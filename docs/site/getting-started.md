# Getting started

Four steps from nothing to a generated image:

1. **[Install the server](getting-started-install.md)** — PyPI, source, or Docker
2. **[Configure](getting-started-configure.md)** — point it at your ComfyUI instance
3. **[Add it to your MCP client](getting-started-clients.md)** — OpenCode, Claude Desktop, Cursor, or any MCP host
4. **[Hold a first session](getting-started-first-session.md)** — generate an image end to end

Prerequisites: a running ComfyUI instance (local or remote), Python 3.12+ if
installing from source, and Node.js is *not* required (that's only for these
docs).

New to MCP? The [core concepts](./concepts.md) page explains tools vs resources
vs prompts; the [security model](./security-model.md) explains what the server
does on the agent's behalf.
